CSS Animation

CSS animation allows you to style an element using the animation property or its sub-properties. Using this, you can change the timing, duration, or other details of the animation such as pause state. By using the @keyframesem at-rule, we can define the appearance of an animation. @keyframes uses a percentge to indicate the precise timing of an animation sequence. For instance, 0% means the first moment an animation starts, and 100% indicates the end of the animation. Because the start and end of an animation are so important, they have special aliases: from and to. Both the percentage and alias are optional, and if they are not specified the browser handles the animation by using the computed value of all attributes. It is possible to use additional keyframes to indicate steps between the start and end of an animation, such as 50% for the exact middle. The animation property can be be short hand for: animation-delay, animation-direction, animation-duration, animation-fill-mode, animation-iteration-count, animation-name, animation-play-state, animation-timeline, and animation-timing-function! This means we can save a lot of space in our CSS by using the proper syntax of the animation property. This is good for simple animations but if we want to make more complex animations we need to use the longhand properties of animation. This is because the longhand properties can accept multiple values, which are the separated by commas. Say for example, we want to apply three animations to something. We can separate the animations with commas, and those animations are now locked into a position. In the following line, we can assign durations for each of these animations, and they will apply to each position appropriately. To put it simply, the first animation will follow the properties of the first listed duration, the second animation will follow the second duration listed, and so on and so forth. This is a really neat trick to save code space even if using longform properties! Below I will show you some cool animations I found on the internet.
